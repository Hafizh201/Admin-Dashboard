Buatkan web dashboard admin responsive untuk project “Smart Borrowing System Berbasis IoT Menggunakan ESP32”.

Web ini digunakan untuk monitoring database Google Sheets melalui Google Apps Script Web App. Frontend harus berjalan sebagai web biasa dan mengambil data dari URL Apps Script berikut:

`https://script.google.com/macros/s/AKfycbzESFzQlXoEoYX4xHCa35jQHzwhILd5axxovkxbLxMJar8SSlRZAHytsC3ZiD_Stw62/exec`

Gunakan JavaScript `fetch()` untuk request ke URL tersebut. Jangan gunakan backend lain seperti Node.js, Express, PHP, Firebase, Supabase, MongoDB, MySQL, atau database lain.

PENTING:
Semua request wajib dikirim dengan `body: JSON.stringify(payload)`. Jangan kirim object langsung ke body.

Gunakan helper API berikut:

```javascript
const API_URL = "https://script.google.com/macros/s/AKfycbzESFzQlXoEoYX4xHCa35jQHzwhILd5axxovkxbLxMJar8SSlRZAHytsC3ZiD_Stw62/exec";

async function api(payload) {
  const response = await fetch(API_URL, {
    method: "POST",
    body: JSON.stringify(payload)
  });

  const text = await response.text();

  try {
    return JSON.parse(text);
  } catch (err) {
    console.error("Response bukan JSON:", text);
    return {
      ok: false,
      error: "Response dari server bukan JSON.",
      raw: text
    };
  }
}
```

Buat hasil akhir berupa satu file `index.html` lengkap berisi HTML, CSS, dan JavaScript dalam satu file.

## Struktur Database

Jangan menambah field atau kolom baru. Gunakan struktur database yang sudah ada.

Sheet `Data`:

* `Nama`
* `Level`
* `uid`
* `Kadaluarsa`
* `kelas`

Di API, gunakan field:

* `nama`
* `level`
* `uid`
* `Kadaluarsa`
* `kelas`

Sheet `Riwayat`:

* `uidpeminjam`
* `Idbarang`
* `nama`
* `kelas`
* `mode`
* `waktu`
* `Perpanjang`

Sheet `Barang`:

* `Column 1`
* `namabarang`
* `kategori`
* `dipinjam`
* `lastuser`
* `lastkelas`
* `lastupdate`
* `lastuid`

Catatan penting:
Kolom `Column 1` pada sheet `Barang` adalah UID barang. Namun di API dan UI gunakan nama field `uidbarang`. Jangan tampilkan tulisan `Column 1` di UI. Tampilkan sebagai “UID Barang”.

## Response API

Semua response API menggunakan format:

```javascript
{
  ok: true,
  data: ...
}
```

atau:

```javascript
{
  ok: false,
  error: "pesan error"
}
```

Jika `ok: false`, tampilkan pesan error dengan toast/alert.

## 11. Error Handling

Jika API mengembalikan:

```javascript
{ ok: false, error: "..." }
```

tampilkan pesan error tersebut.

Jika fetch gagal, tampilkan:
“Gagal terhubung ke server Apps Script. Periksa URL API, deployment Apps Script, atau koneksi internet.”

Jika data kosong, tampilkan empty state yang rapi.

Jika response POST hanya berisi pesan:
“POST diterima, tetapi field action belum dikirim.”
maka itu bukan error fatal, tetapi berarti frontend belum mengirim payload dengan action. Pastikan setiap request API mengirim field `action`.

Catatan paling penting:

* Jangan gunakan field `id_siswa`, `id_barang`, `id_riwayat`, `created_at`, `updated_at`, `status`, `catatan`, atau field lain yang tidak ada.
* Jangan tampilkan `Column 1` di UI. Gunakan label “UID Barang”.
* Jangan menambah kolom baru.
* Semua tabel dan form harus mengikuti struktur database yang disebutkan.
* Hasil akhir harus langsung bisa dipakai sebagai `index.html`.
