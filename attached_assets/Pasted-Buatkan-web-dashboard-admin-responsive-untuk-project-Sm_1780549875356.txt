Buatkan web dashboard admin responsive untuk project “Smart Borrowing System Berbasis IoT Menggunakan ESP32”.

Web ini digunakan untuk monitoring database Google Sheets melalui Google Apps Script Web App. Frontend harus berjalan sebagai web biasa dan mengambil data dari URL Apps Script berikut:

https://script.google.com/macros/s/AKfycbwsquXFtrhmz_vFFeTOoU6AiwIwYvmIH21hlTH6URUfZ5KNDKt897xY1b-Sm_mUU3Ou/exec

Gunakan JavaScript `fetch()` untuk request ke URL tersebut. Jangan gunakan backend lain seperti Node.js, Express, PHP, Firebase, Supabase, MongoDB, MySQL, atau database lain.

PENTING:
Jangan menambah field atau kolom baru. Gunakan struktur database yang sudah ada.

Struktur sheet asli:

Sheet `Data`:

* `Nama`
* `Level`
* `uid`
* `Kadaluarsa`
* `kelas`

Sheet `Riwayat`:

* `uidpeminjam`
* `Idbarang`
* `nama`
* `kelas`
* `mode`
* `waktu`
* `Perpanjang`

Sheet `Barang`:

* `Column 1` sebagai UID barang
* `namabarang`
* `kategori`
* `dipinjam`
* `lastuser`
* `lastkelas`
* `lastupdate`
* `lastuid`

Catatan penting:
Walaupun di sheet `Barang` kolom UID barang bernama `Column 1`, di API gunakan nama field `uidbarang`. Jangan tampilkan tulisan `Column 1` di UI. Tampilkan sebagai “UID Barang”.

Gunakan helper API berikut:

```javascript
const API_URL = "https://script.google.com/macros/s/AKfycbyDlUHBa-YPsv2EN3iprkSMPLdWC7o_hZ80ixXnux1huALJmeFB0a-Uxh5L-F7g7ObH/exec";

async function api(payload) {
  const response = await fetch(API_URL, {
    method: "POST",
    body: JSON.stringify(payload)
  });

  const text = await response.text();

  try {
    return JSON.parse(text);
  } catch (err) {
    return {
      ok: false,
      error: "Response dari server bukan JSON.",
      raw: text
    };
  }
}
```

Buat hasil akhir berupa satu file `index.html` lengkap berisi HTML, CSS, dan JavaScript dalam satu file.

Fitur utama:

1. Login Admin

* Tampilkan halaman login PIN.
* Saat login, panggil:

```javascript
api({ action: "login", pin })
```

* Jika berhasil, simpan PIN ke `sessionStorage`.
* Semua request berikutnya wajib menyertakan PIN.
* PIN default: `123456`.

2. Dashboard
   Setelah login, panggil:

```javascript
api({ action: "bootstrap", pin })
```

Response berisi:

* `data.data` dari sheet `Data`
* `data.barang` dari sheet `Barang`
* `data.riwayat` dari sheet `Riwayat`
* `data.stats` untuk statistik dashboard

Tampilkan statistik:

* Total siswa
* Siswa aktif
* Siswa kadaluarsa
* Total barang
* Barang tersedia
* Barang dipinjam
* Total riwayat
* Riwayat hari ini
* Total mode Pinjam
* Total mode Kembali
* Total mode Perpanjang

3. Grafik Dashboard
   Gunakan Chart.js CDN untuk:

* Grafik kategori barang
* Grafik status barang dari field `dipinjam`
* Grafik mode riwayat dari field `mode`
* Grafik aktivitas 7 hari terakhir dari field `waktu`

Gunakan data:

```javascript
stats.kategori_barang

stats.mode_riwayat

```

* `Kadaluarsa`
* `kelas`

Tabel hanya berisi:

* Nama

* Kelas

Fitur:

* Tambah siswa

* Search berdasarkan nama, level, UID, Kadaluarsa, dan kelas


11. Error Handling
    Jika API mengembalikan:

```javascript
{ ok: false, error: "..." }
```

tampilkan pesan error tersebut.

Jika fetch gagal, tampilkan:
“Gagal terhubung ke server Apps Script. Periksa URL API, deployment Apps Script, atau koneksi internet.”

Jika data kosong, tampilkan empty state yang rapi.

Catatan paling penting:

* Jangan gunakan field `id_siswa`, `id_barang`, `id_riwayat`, `created_at`, `updated_at`, `status`, `catatan`, atau field lain yang tidak ada.
* Jangan tampilkan `Column 1` di UI. Gunakan label “UID Barang”.
* Semua tabel dan form harus mengikuti struktur database yang disebutkan.
* Hasil akhir harus langsung bisa dipakai sebagai `index.html`.
